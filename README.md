# Fish and Ships
Fish and ships is a resource management spaceship game.
You play as a almost stranded human, coming back from a exploration of Uranus.
Your ship is breaking by the minute and you need to repair it using resources from asteroids.

How to play
1. Play on itch
https://martycat111.itch.io/fish-and-ships
2. Download precompiled
Go to the Github releases latest tag and download the executable for your system.
4. Run locally
```
git clone --depth 1 https://github.com/Martycat111/fish
```
